      免費模式與資料範圍

      本版不用你的 API 金鑰，也不連結 Cloud 計費。

      1. 底圖預設使用 OpenStreetMap，可平移、縮放、點選及繪製。
      2. 街景使用 Google 舊式街景嵌入相容模式，在右側框切換。此入口並非 Google 正式 Embed API 的保證介面，Google 可能變更或沒有該處影像。街景中前進不會同步地圖選點，加入路線仍採你在地圖點的位置。
      3. 路線公里與逐步文字取自 Valhalla / OpenStreetMap 機車模型。這是模型估時，不是 Google 或尖峰實測，未包含完整早尖峰、號誌及待轉停等。

      無法自動取得全程必經紅綠燈、目前各路口秒數或合法直接左轉規則。逐點標註的數量只涵蓋你標的點；待轉與現場車道仍需核對。

      點道路，預覽完整走法

      1. 選 A／B 或自己的方案，按「點選調整」。
      2. 新增：指定兩點之間；移動：指定要取代的點；替換：指定起訖點，移除中間舊點。
      3. 點目標道路，同頁看街景，再按「預覽這個走法」。
      4. 確認完整藍線、轉彎文字、全程公里與模型時間，再按「採用並保存」。
      5. 失敗、取消與切換方案會丟棄預覽，已保存方案保留。

      街景框內移動不會回傳位置，選點以地圖為準。計算偏離原點超過 30 公尺時要求重選。

      路線比較

      路線／資料狀態道路公里預估時間／來源相對基準操作

      其他路線只在道路來源、機車模式及起終點（30 公尺內）相同時比較模型時間。尚未計算的方案可逐條補算、預覽後保存；不會自動覆蓋舊方案。估時不包含完整晨峰、紅燈及待轉時間。
